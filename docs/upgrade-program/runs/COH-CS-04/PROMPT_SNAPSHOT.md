# PROMPT COH-CS-04: Ideation 2.0 - Opportunity-Led, Evidence-Aware and Reuse-Aware Ideation

## Objective
Upgrade the existing Ideation Workspace to follow the mental model:
`Situation or Source -> Communication Opportunities -> Evidence Check -> Reuse Check -> Strong Idea -> Content Brief`
Generate fewer, more useful, better-grounded opportunities while preserving existing COH strategy (audiences, channels, pillars, quality filters, depth levels, Protected Kernel, claim rules) and without introducing Turbocharger concepts, embeddings, or a database.

## Key Requirements
1. Preserve existing COH strategy and use the shared Context Compiler.
2. Expand idea quality with digestible primary cards and expandable secondary intelligence (`communicationJob`, `coreTension`, `desiredAudienceResponse`, `availableEvidence`, `evidenceStillRequired`, `suggestedAudience`, `suggestedChannel`, `suggestedFormat`, `suggestedPillar`, `strategicAngle`, `reuseOpportunity`, `riskToAvoid`, `unresolvedAssumptions`).
3. Define COH-specific Communication Jobs answering `Why should this content exist?`.
4. Separate Available Evidence from advisory Evidence Still Required without placeholder-heavy blockers.
5. Inspect real Idea Library and Content Library items for Reuse Awareness (`New Ground`, `Extend Existing Idea`, `Reframe Existing Content`, `Reuse Existing Argument`) with conservative confidence and direct inspection links.
6. Enforce Opportunity Diversity across communication job, audience, strategic angle, evidence emphasis, and narrative perspective.
7. Support both source-grounded ideation and topic-only ideation.
8. Carry full context forward when promoting an idea to Content Workspace.
