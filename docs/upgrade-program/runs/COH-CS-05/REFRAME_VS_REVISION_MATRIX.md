# REFRAME VS REVISION MATRIX (COH-CS-05)

## Core Distinction

- **Revision (`REVISION`)**: Improve substantially the same communication job (clarity, brevity, grammar, tone warmth, direct translation).
- **Reframing (`REFRAME`)**: Change what the content is trying to become (audience, familiarity level, strategic frame, communication purpose, or channel/format architecture) while preserving factual integrity.

| User Instruction | Resolved Route | Rationale | Studio Action |
|---|---|---|---|
| `"Make this 25% shorter and smoother"` | `REVISION` | Preserves existing audience, channel, and communication job; only adjusts length and prose flow. | Displays Revision Studio recommendation alert with one-click **Open in Revision Studio** handoff. |
| `"Fix grammar, remove repetition, and polish the tone"` | `REVISION` | Editorial cleanup of the same piece without shifting strategic angle or audience. | Recommends Revision Studio handoff. |
| `"Translate this directly into European Portuguese"` | `REVISION` | Direct linguistic localization of the same communication job. | Recommends Revision Studio handoff. |
| `"Make this useful to a cultural institution that knows little about COH and needs to understand why this belongs in its programming strategy"` | `REFRAME` | Shifts target audience (`Cultural Institutions & Museums`), lowers familiarity assumption (`low`), and changes purpose to curatorial/programming relevance. | Resolves editable `ResolvedReframePlan` and generates institutional reframe. |
| `"Adapt this internal partner memo into a public LinkedIn post focused on climate literacy"` | `REFRAME` | Shifts channel (`LinkedIn`), audience (`General Public & Communities`), and strategic pillar (`Climate & Sustainability Literacy`). | Resolves editable `ResolvedReframePlan` and generates channel/pillar reframe. |
| `"Turn this project description into a press-facing narrative highlighting artistic innovation"` | `REFRAME` | Changes narrative perspective to press-facing and reframes around `Artistic & Musical Innovation`. | Resolves editable `ResolvedReframePlan` and generates press narrative reframe. |
